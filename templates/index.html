HOW IT WORKS

Several signals. One simple report.

Connection

02

Structure

Examines URL length, domain structure and IP-based URLs.

03

Indicators

Looks for suspicious keywords, @ symbols and URL shorteners.

LIMITATION

SecureURL is a student-built rule-based project. It does not query threat-intelligence databases and should not be used as the sole basis for a security decision.
